# Commits

The commits have to follow the format defined by `git-cc` from [InkordiousDotfiles](https://gitlab.com/axxel-otl/InkordiousDotfiles/-/blob/core/bedrock/.local/bin/git-cc) if you use bedrock or [InkordiousDotfiles](https://gitlab.com/axxel-otl/InkordiousDotfiles/-/blob/core/arch/.local/bin/git-cc). Using my dotfiles is optional; any tool that creates the same format is valid and you can even make it manually.

`git-cc` is my recommendation to grant the correct format.
